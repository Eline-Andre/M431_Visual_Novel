Visual Novel - Projet scolaire pour le cours M431 (Avril-Juin 2026)

Un Visual Novel est un type de jeu vidéo narratif, originaire du Japon et particulièrement populaire en Asie de l'Est. Le joueur interagit avec les personnages à travers des dialogues et des choix qui influencent l'histoire. Le jeu est aussi accompagné d'illustrations et de musiques. Selon les décisions prises, plusieurs fins sont possibles.

Toutes les trois, nous avions déjà joué à plusieurs Visual Novels (comme par exemple Dangaronpa, Ace Attorney, etc.), ce qui nous a donné envie de nous lancer dans le développement de ce type de jeu pour notre projet scolaire.
